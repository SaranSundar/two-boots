# Two Boots Legend

A classic 2D platformer game built with PixiJS 8, recreated from a 9th grade Computer Science final project.

## Play Now

🎮 **[Play the game here](https://saransundar.github.io/two-boots/)** 🎮

## About

This is a basic platformer game that showcases:
- Grid-based level design loaded from text files
- Physics-based movement with gravity and jumping
- Tile-based collision detection
- Collectible coins and hazards
- 4 challenging levels
- Mobile-friendly virtual controls
- Retro pixel art graphics

## Controls

**Desktop:**
- Arrow Keys: Move left/right
- Space: Jump
- ESC: Pause

**Mobile:**
- Virtual D-pad: Move left/right
- Jump button: Jump

## How to Play

- Navigate through each level by jumping across platforms
- Collect coins for points
- Avoid spikes - they're deadly!
- Reach the door to complete the level
- Don't fall off the world!

## Development

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Deploy to GitHub Pages
```bash
npm run deploy
```

## Technologies Used

- **PixiJS 8** - 2D WebGL renderer
- **TypeScript** - Type-safe JavaScript
- **Vite** - Fast build tool
- **AssetPack** - Asset optimization and processing
- **Motion** - Animation library
